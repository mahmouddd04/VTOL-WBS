# VTOL-WBS-100 — Tail-Sitter Project Management Tracker

Interactive project management tracker developed for a **Flying Wing Tail-Sitter VTOL Phase I Design Package**.

## Purpose

This project applies project-management concepts learned during the **EGSA Project Management Training** to an engineering development workflow.

## Features

- Work Breakdown Structure (WBS)
- Project scheduling and task dependencies
- Critical Path tracking
- Risk register and mitigation planning
- Resource allocation and conflict management
- Progress tracking
- Schedule and risk simulation
